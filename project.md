# Project Overview: SprintReady (FKA HireMe)

## Core Mission
SprintReady is a B2B2C developer assessment and placement engine. It converts passive student candidate profiles (GitHub repositories, commits, architecture patterns) into an objective 360° Readiness Index and a 48-Hour Sprint Plan to bridge role gaps.

## Target Audience
- **Students (B2C Magnet):** Engineering students seeking targeted, role-specific placement preparation.
- **Recruiters (B2B Engine):** Employers seeking pre-vetted candidates filtered by actual code quality and sprint execution, not PDF resumes.

## MVP Scope Constraints
- **Zero Cash Cost:** Strictly utilize free tier infrastructure (Firebase Auth, GitHub API, Supabase PostgreSQL, Vercel/Render, Gemini 1.5/2.0 Flash Free API).
- **Single Sprint Mode:** Focus strictly on role-based Sprints (48h - 1 month) with customizable completion tracking.
- **Goal-Based Lanes:** Hardcoded target roles (e.g., Backend Developer - Go/Python, Frontend - React) with preset architectural rubrics instead of noisy free-text JD parsing.
