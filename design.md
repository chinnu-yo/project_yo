# Design System & UI Specifications

## Aesthetics & Theme
- **Theme:** Dark mode by default (`slate-950` background, `emerald-500` accents for verified metrics, `amber-400` for sprint warnings).
- **Typography:** Inter or JetBrains Mono for code blocks and metrics.
- **Vibe:** Developer-first dashboard (resembling GitHub Insights, Vercel, and Linear UI).

## Primary UI Components
1. **Auth & Setup:** Clean OAuth login landing screen with single-click "Connect GitHub".
2. **Goal Selector:** Selection cards for target roles (e.g., Backend SDE-1, Frontend SDE-1) and company tier target (Startup vs Big Tech).
3. **Gap Audit View:** Radar chart or progress bars comparing user's GitHub signals against role standards (Test Coverage, Architecture, Dependency Health).
4. **Sprint Execution Board:** 3-step actionable milestone tracker showing checkpoint descriptions, free resource links, and GitHub PR submission fields.
5. **Verified Candidate Badge Profile:** Shareable candidate profile card detailing verified proof-of-work metrics.
